# Sebastian Damman — *Vande Volhardinghe der Heylighen* (1615)

**On the Perseverance of the Saints**, written in reply to Petrus Bertius. Printed in Enchuysen by Jacob Lenaertsz Meyn, 1615.

## About this edition

This repository pairs a historical Dutch transcription with a complete English reading translation: six introductory texts and 23 body sections. It is a reading edition, not a critical edition. The transcription follows a British Library scan except for the opening question, which retains the earlier source transcription. Scans are not included.

The Dutch retains historical spelling, transcription doubts and unreadable passages. The English translates the retained Dutch where it makes sense in context; brief notes flag unresolved differences of meaning. Marginal citations are retained in braces. The printer’s errata table preserves the Dutch error and correction side by side; some errata remain unresolved.
